THE SELF-HOSTING DILEMMA

Got a great PC, but hosting feels like a nightmare?

You already have a 16–64 GB gaming rig sitting on your desk. But hosting a Minecraft server manually used to mean router logins, CGNAT roadblocks, Java version mismatches, and forcing your friends to download sketchy VPNs.

× THE OLD MANUAL WAY FRUSTRATING & SLOW
  • × Router & CGNAT Hell: Logging into 192.168.1.1, fighting ISP port blocks, and exposing your private home IP address to random players.
  • × Java Version Chaos: MC 1.21 requires Java 21, MC 1.16 requires Java 8. One wrong PATH setting and your server crashes on launch.
  • × Forcing Friends to Install VPNs: Begging your friends to set up Hamachi, Radmin, or Radmin VPN just to connect to your world.
  • × Mobile & Console Friends Left Out: Bedrock players on phones, Switch, and Xbox can't join unless you manually compile and configure Geyser.
  • × Aternos & Free Host Suffering: 30-minute queue lines, 2 GB RAM throttling, tick lag on modpacks, and automatic shutdowns when empty.
✓ THE CRAFTORBIT WAY 1-CLICK SIMPLICITY
  • ✓ Zero Router Setup: Built-in playit.gg tunnels generate a public *.gl.joinmc.link domain in seconds. Your home IP stays private and DDoS-protected.
  • ✓ Intelligent Java Resolver: Scans your system and automatically selects the exact Java runtime (8, 17, 21, or 25) required by your Minecraft version.
  • ✓ Zero Extra Apps for Friends: Anyone can join directly through their normal Minecraft multiplayer menu by entering the public tunnel address.
  • ✓ Automated Bedrock Cross-Play: Bundled GeyserMC and Floodgate bridge Android, iOS, Xbox, Switch, and PlayStation players into your Java server.
  • ✓ Full Unthrottled PC Hardware: Dedicate 8GB, 16GB, or 32GB of your own RAM and CPU cores with 0s startup, 20.0 TPS, and no idle shutdown.
